ClipSync 개인정보처리방침
시행일: 2026년 10월 21일 · 문서 버전: 1.0
운영자·개인정보 관련 문의: Horizon Entertainment
이메일: apps@horizonent.co.kr

1. 적용 범위와 기본 원칙

이 방침은 Horizon Entertainment가 제공하는 Windows·macOS용 ClipSync 데스크톱 앱의 개인정보 처리와 이용자의 관리 방법을 설명합니다. ClipSync는 로컬 클립보드 관리자이자 사용자가 연결한 컴퓨터 사이의 P2P 동기화 도구입니다. 회원 가입, 광고 추적, 사용 통계·클립보드 내용을 운영자 서버로 자동 전송하는 기능은 제공하지 않습니다.

클립보드에는 개인정보나 비밀정보가 포함될 수 있습니다. 앱 실행 중 기록 수집과 기기 연결 후의 자동 동기화 범위를 확인하고, 신뢰하는 컴퓨터만 연결해 주세요. 이 방침은 홈페이지·GitHub 등 다운로드 서비스 전체의 접속기록 처리에 관한 방침을 대신하지 않습니다.

2. 앱이 기기에서 처리하는 정보와 목적

가. 클립보드 기록: 새로 복사한 일반 텍스트, 이미지, 파일 이름·크기·경로·해시, 기록 시각, 로컬/원격 출처, 고정 상태와 미리보기를 기록 검색·다시 복사·동기화·전송 무결성 확인에 사용합니다. 파일 원본 자체를 기록 보관용으로 추가 복사하지 않고 경로를 참조하며, 클립보드 이미지는 캐시 파일로 관리합니다. 동기화를 위해 수신하는 파일은 별도로 다운로드 폴더에 저장합니다.

나. 연결 정보: 사용자가 정한 연결 키와 비밀번호를 같은 그룹의 기기 발견·인증·통신 암호화에 사용합니다. 비밀번호 원문은 설정 파일에 저장하지 않습니다. 자동 연결을 위해 연결 키, 기기 식별자, 도출한 인증·암호화 키, 기기 연결용 키 정보, 이전에 인증한 기기의 공개 키와 탐색 노드 주소를 기기에 저장할 수 있습니다.

다. 네트워크 정보: IP 주소·포트·공개 키·그룹 탐색용 식별 정보는 LAN 탐색, 공개 분산 탐색망(DHT), 상대 컴퓨터와의 연결 협상에 사용합니다. 연결 협상에서는 기기 이름(운영체제의 컴퓨터 이름), 기기 식별자와 인증용 정보를 교환합니다. LAN의 일부 연결·탐색 정보는 같은 네트워크의 다른 참여자가 관찰할 수 있습니다. 클립보드 본문과 전송 파일은 인증 절차 후 암호화하여 전송합니다.

라. 설정과 동작 상태: 테마·단축키·창 위치와 크기·창 고정·자동 시작·기록 유지 설정, 앱·운영체제 버전, CPU 종류, 연결·전송 상태 등을 기능 제공과 오류 안내에 사용합니다. 진단 정보는 앱에서 확인하거나 사용자가 '연결 상태 복사'를 눌러 복사하는 경우에만 제공하며 운영자에게 자동 전송하지 않습니다.

3. 연결된 컴퓨터와 외부 서비스에 전달되는 정보

사용자가 같은 연결 키·비밀번호로 연결한 컴퓨터에는 새로 복사한 클립보드와 명시적으로 다시 복사한 기록이 자동 동기화될 수 있습니다. 동일한 연결 정보를 아는 다른 사용자가 그룹에 참여할 수 있으므로 키·비밀번호를 비밀로 관리해야 합니다. 상대 컴퓨터에는 내용·파일 이름·관련 전송 정보가 전달되며 상대 기기에도 기록·파일이 남을 수 있습니다.

전용 클립보드 중계·저장 서버를 운영하지 않습니다. 다만 공개 DHT 노드와 통신 상대는 기기 발견·연결을 위해 IP 주소·포트·공개 키·탐색 식별 정보 같은 네트워크 메타데이터를 처리할 수 있습니다. 이러한 노드와 상대 기기는 국외에 위치할 수 있으며, 운영자가 모든 탐색 노드의 위치·보관 방식을 통제하지는 않습니다. 탐색용 식별 정보는 연결 정보에서 도출하며 클립보드 본문·파일 내용을 탐색망에 저장하지 않습니다.

운영자는 앱의 클립보드 내용을 광고·판매 목적으로 제공하지 않습니다. 다운로드·문의에 이용하는 웹사이트, GitHub, 이메일 서비스는 각 서비스의 접속기록·보안·보관 정책이 적용될 수 있습니다. 개발자 이메일 버튼은 사용자의 메일 프로그램을 여는 기능이며 메시지나 진단 자료를 자동으로 보내거나 첨부하지 않습니다.

4. 보관 장소와 기간

가. 기본 기록: 메모리에서 최대 100개, 텍스트 원문 합계 4MiB까지 관리하고 한도를 넘으면 오래된 항목을 정리합니다. 기본 설정에서는 앱 종료 시 기록을 보관하지 않습니다. 이미지 임시 캐시는 정상 종료 시 정리하며, 강제 종료·시스템 장애가 있으면 임시 파일이 남을 수 있습니다.

나. 기록 유지 옵션: 사용자가 '종료 후에도 클립보드 기록 유지'를 켠 경우에만 다음 실행을 위한 기록을 저장합니다. 텍스트·파일 경로·기록 속성은 운영체제 보안 저장소를 이용해 암호화한 history.enc에 보관합니다. 이미지는 사용자별 앱 데이터의 history-images 폴더에 파일로 보관하며 이미지 바이트 자체를 별도로 암호화하지 않습니다. 파일 기록은 원본 경로를 참조하므로 원본의 이동·삭제에 영향을 받습니다. 기록 유지에도 개수·텍스트 용량 제한을 적용합니다.

다. 자동 연결 정보: connection.enc는 Windows DPAPI, macOS Keychain 등 운영체제 보안 저장소를 이용해 암호화합니다. 운영체제 보안 저장소를 사용할 수 없으면 평문 파일로 대신 저장하지 않습니다. 저장한 연결은 사용자가 '연결 해제 및 저장 삭제'를 누를 때까지 자동 연결을 위해 보관합니다.

라. 설정: 사용자별 앱 데이터 폴더와 운영체제의 로그인 항목에 저장하며 사용자가 설정을 변경·해제하거나 관련 데이터를 삭제할 때까지 유지할 수 있습니다.

마. 수신 파일: 다운로드 폴더의 ClipSync에 저장하며 사용자가 직접 지울 때까지 남습니다. 기록 삭제·옵션 해제·앱 종료·앱 제거만으로 수신 파일이나 사용자 원본을 자동 삭제하지 않습니다. 앱 제거 후에도 사용자 데이터가 남을 수 있습니다.

5. 이용자의 확인·삭제·동기화 제어

기록의 '삭제'로 개별 항목을 제거하고 '비우기'로 고정하지 않은 항목을 정리할 수 있습니다. 모든 기록을 지우려면 고정 항목도 별도로 삭제해야 합니다. 더 이상 참조하지 않는 앱 소유 이미지 캐시는 정리합니다.

기록 유지 옵션을 끄면 저장한 기록 파일을 삭제하며 현재 실행에서 사용하는 기록·이미지 참조는 종료까지 유지한 뒤 정리합니다. 다음 실행에는 해당 기록을 복원하지 않습니다. 저장된 기록을 복원하는 동작 자체가 다른 기기로 내용을 전송하지는 않습니다.

'일시정지'로 자동 동기화·수신을 중지하고 '연결 해제 및 저장 삭제'로 이 PC의 그룹 연결과 저장된 연결 정보를 제거할 수 있습니다. 비밀번호를 바꾸거나 그룹 전체의 접근 권한을 바꾸려면 각 기기에서 연결을 해제한 뒤 새 키·비밀번호로 다시 연결하세요. '부팅 시 시작'을 해제하면 이 앱의 자동 시작 등록을 제거합니다.

다운로드 파일과 앱 데이터는 사용자가 운영체제에서 직접 삭제할 수 있습니다. 앱을 완전히 종료한 상태에서 앱 데이터 삭제를 진행하세요. 이미 상대 컴퓨터에 전달한 내용·파일·백업은 이 PC에서 지워도 원격으로 삭제되지 않습니다. 상대 기기 소유자에게 별도로 삭제를 요청해야 합니다. 일반 파일 삭제는 운영체제·디스크·백업에 남은 모든 복사본의 완전 삭제를 보장하는 기능이 아닙니다.

6. 문의 이메일로 제공하는 정보

사용자가 apps@horizonent.co.kr로 문의하면 이메일 주소, 문의 내용, 사용자가 첨부한 진단 자료·파일을 문의 대응에 필요한 범위에서 처리합니다. 연결 키·비밀번호나 불필요한 클립보드 원문·타인의 개인정보를 보내지 마세요. 문의 자료는 처리 목적을 달성하면 불필요한 정보를 지체 없이 정리·삭제하며, 법령상 보관 의무가 있는 경우에는 해당 범위와 기간을 따릅니다. 열람·정정·삭제·처리정지 문의도 같은 주소로 할 수 있습니다. 운영자가 보유하지 않는 기기 내 기록과 상대 컴퓨터의 복사본은 각 기기에서 관리해야 합니다.

7. 보호 조치와 사용 시 유의사항

연결 인증, 내용 암호화, 전송 파일의 SHA-256 확인, OS 보안 저장소, 사용자별 앱 데이터와 제한된 렌더러 권한을 사용합니다. 다만 기기 잠금 해제 상태, 악성 프로그램, 같은 OS 계정, 외부 백업·보안 프로그램 또는 연결된 상대 기기에 의한 접근까지 막는 기능은 아닙니다. 자동 동기화 중에는 암호·인증번호·기밀자료도 사용자가 복사한 내용에 포함될 수 있으므로 필요할 때 먼저 일시정지하거나 연결을 해제하세요.

8. 방침의 변경과 연락처

처리 범위나 기능이 바뀌면 앱에 포함된 방침과 배포 문서에 시행일·문서 버전을 표시하여 알립니다. 별도 동의가 필요한 처리를 추가할 때에는 관련 법령에 따른 절차를 따릅니다.
