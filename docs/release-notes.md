# ClipSync 0.4.7 · 창 크기 조절·기록 유지·Mac 창 열기 수정

창 가장자리·모서리를 드래그해 가로·세로 크기를 조절할 수 있습니다. 최소 크기는 360×480이며 크기와 위치는 다음 실행에도 복원합니다. 필터 버튼은 창 가로폭에 맞춰 비율대로 늘어납니다.

Windows는 기존 투명 배경 A 아이콘의 내부 여백을 줄여 작은 표시 영역을 더 크게 채웁니다. 실행 파일·설치 파일·창 아이콘에 적용하고 트레이에는 16·20·24·32·48·64px가 포함된 전용 ICO를 사용합니다. 창을 열면 작업표시줄에도 표시합니다. Mac 앱·메뉴바 아이콘은 유지합니다.

선택한 기록은 굵은 청록색 테두리·왼쪽 강조선·강한 배경·‘선택됨’ 배지로 구분합니다. 고정한 항목이 위에 있어도 선택한 기록을 정확히 표시합니다. 카드의 빈 영역을 누르면 선택하고, 내용이나 복사를 누르면 클립보드에 복사합니다.

환경설정에 **종료 후에도 클립보드 기록 유지**를 추가했습니다. 기본값은 꺼짐입니다. 켜면 텍스트 원문·이미지·파일 참조·고정 상태를 재실행 후 복원합니다. 최대 100개·텍스트 합계 4MiB 제한은 유지합니다. 텍스트와 경로는 OS 보안 저장소로 암호화하고 이미지는 사용자별 앱 전용 폴더에 보관합니다. 파일은 원본이 남아 있어야 재사용할 수 있습니다. 옵션을 해제하면 저장된 기록을 지우고 현재 실행의 기록도 종료 시 사라집니다. 복원한 기록은 자동으로 다른 기기에 전송하지 않습니다.

Mac에서 메뉴 닫힘·Dock 활성화 같은 일시적인 포커스 변화로 창이 열리자마자 숨겨지는 동작을 수정했습니다. 메뉴의 ‘ClipSync 열기’는 창을 표시하며, 포커스를 잃어도 유지합니다. ×·Esc·창 단축키로 숨기며 오른쪽 아래 종료는 앱을 종료합니다.

[변경과 검증 기록](https://github.com/limfrog/ClipSync/blob/main/docs/window-history-verification.md)

설치 전 기존 앱을 **종료**한 뒤 업데이트하세요. 기존 연결 키·비밀번호와 설정은 유지합니다. 기록을 다음 실행에 남기려면 업데이트 후 환경설정에서 새 옵션을 켜세요. 이미 종료되어 사라진 구버전 기록은 복구할 수 없습니다.

Windows x64: `ClipSync-0.4.7-Windows-x64-Setup.exe` · Apple Silicon: `ClipSync-0.4.7-macOS-arm64.pkg` · Intel Mac: `ClipSync-0.4.7-macOS-x64.pkg`. `SHA256SUMS.txt`를 제공합니다. Windows 배포자 인증서 서명·Apple 공증은 포함하지 않으며 Mac 앱은 ad-hoc 서명입니다.
