# ClipSync 0.4.9 · 빌드 9

새 버전을 찾기 위해 GitHub를 직접 방문해야 했던 불편을 줄였습니다. 설치된 앱이 실행 후와 6시간마다 공식 GitHub 릴리스를 확인하고, 새 버전이 있으면 OS 알림과 앱 안의 다운로드 안내를 표시합니다. 같은 버전의 OS 알림은 다시 실행해도 반복하지 않습니다.

- 환경설정에 **새 버전 자동 확인**, **업데이트 확인**, **새 버전 다운로드**를 추가했습니다. 자동 확인을 꺼도 수동 확인은 가능합니다.
- Windows x64·Mac Apple Silicon·Mac Intel에 맞는 설치 파일을 브라우저에서 바로 다운로드합니다. 받은 뒤 ClipSync를 종료하고 설치하세요. 무인 자동 설치는 제공하지 않습니다.
- 숫자로 버전을 비교해 이전 버전으로 내려가지 않으며, 초안·준비 중인 설치 파일·다른 저장소 주소를 다운로드하지 않습니다. GitHub 미리보기 릴리스에는 미리보기 표시를 붙입니다.
- 네트워크 오류·요청 제한은 최신 버전으로 잘못 표시하지 않습니다. 연속 확인 요청을 제한하고 타임아웃과 응답 크기 제한을 적용합니다.
- GitHub 버전 확인과 다운로드 동작을 반영하여 개인정보처리방침·이용약관을 문서 1.1로 갱신했습니다. 클립보드·연결 비밀·기기 이름은 업데이트 확인에 전송하지 않습니다.

Windows 배포자 서명과 Apple 공증은 아직 포함하지 않습니다. 기존 0.4.8 앱에는 확인 기능이 없으므로 이번 버전은 직접 설치해야 합니다.
