# ClipSync 0.4.0 · P2P 클립보드 그룹

- 창 상단 로고와 빈 제목 영역을 드래그해 이동할 수 있으며, 다음 실행에 위치를 복원합니다. 설정 버튼은 톱니 아이콘입니다.
- 모든 PC가 동등한 P2P 참여자로 연결됩니다. 같은 영문·숫자 20자리 연결 키와 8자 이상의 비밀번호를 입력하면 자동으로 상대를 찾습니다.
- 별도 호스팅·유료 중계 없이 공개 HyperDHT로 기기를 발견하고 PC끼리 직접 암호화 전송합니다. 공개 탐색망은 필요하며 UDP 차단·일부 NAT/CGNAT에서는 연결이 실패할 수 있습니다. 유료 중계로 자동 전환하지 않습니다.
- 비밀번호 원문을 저장하지 않고 도출한 연결 정보를 운영체제 보안 저장소로 암호화합니다. 앱 재실행·상대 PC 재실행 후 같은 그룹에 복귀하며, 한 PC가 종료돼도 다른 PC끼리의 연결은 계속됩니다. 보안 저장소가 없는 환경은 현재 실행에서만 연결합니다.
- 연결 해제는 해당 PC의 저장 정보를 삭제합니다. 창 ×·Esc는 숨기고 동기화를 유지합니다. Mac은 Dock에서 숨겨지고 메뉴바에 남으며, 오른쪽 아래 종료는 앱을 완전히 종료합니다.
- 텍스트·이미지·500MB 파일, 한글 파일명 보존과 클립보드 기록 기능은 유지합니다. 느린 연결에서는 진행 중인 파일을 고정된 전체 시간 제한으로 취소하지 않습니다.

연결할 PC를 모두 **0.4.0**으로 업데이트하고 같은 키·비밀번호를 새로 설정하세요. 0.3.x 초대 코드는 호환되지 않습니다. 설치 전 실행 중인 앱을 **종료**하세요. macOS 13 이상이 필요하며 폴더·macOS .app은 ZIP으로 압축하세요.

배포자 인증서 서명과 Apple 공증은 포함하지 않습니다. macOS 앱에는 ad-hoc 서명이 있습니다.

검증 범위와 한계는 [P2P 검증 기록](https://github.com/limfrog/ClipSync/blob/main/docs/p2p-verification.md)을 확인하세요. 이 클라우드에서는 공개 DHT 라우팅 노드를 확보하지 못해 서로 다른 실제 외부망의 NAT 통과를 검증하지 못했습니다. Mac Dock 및 Windows/macOS 간 실제 복사·붙여넣기는 실기기 확인이 필요합니다.

Windows x64: `ClipSync-0.4.0-Windows-x64-Setup.exe` · Apple Silicon: `ClipSync-0.4.0-macOS-arm64.pkg` · Intel Mac: `ClipSync-0.4.0-macOS-x64.pkg`. 파일 SHA-256은 `SHA256SUMS.txt`에서 확인하세요.
