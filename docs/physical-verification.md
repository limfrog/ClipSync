# Mac–Windows 실물 검증

두 기기에서 같은 ChatGPT 대화를 열어 결과를 모을 수 있습니다. ChatGPT 접속만으로 로컬 앱을 조작하거나 클립보드를 읽을 수는 없습니다. 아래 조작은 각 기기에서 직접 수행하고, 양쪽의 연결 상태와 관찰 결과로 원인을 좁힙니다.

## 준비

1. 두 PC의 ClipSync를 오른쪽 아래 **종료**로 닫고 같은 수정 버전을 설치합니다. Apple Silicon/Intel Mac 설치 파일은 서로 다릅니다.
2. 같은 공유기의 일반 Wi-Fi/LAN을 사용합니다. 게스트 Wi-Fi·AP 격리·VLAN은 기기 간 통신을 막을 수 있습니다. VPN 사용 여부도 결과에 함께 적어 주세요.
3. Mac: 시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → ClipSync 허용(해당 설정이 있는 macOS). Windows: Windows 보안 → 방화벽 및 네트워크 보호 → 앱 허용에서 ClipSync 확인. 신뢰하는 홈 네트워크는 개인 프로필을 사용합니다. 방화벽 전체를 끄지 않습니다.
4. ClipSync의 연결 화면에서 양쪽에 같은 20자리 영문·숫자 키와 8자 이상 비밀번호를 입력합니다. 키·비밀번호를 이 문서나 ChatGPT에 보내지 마세요.

## 연결 확인

- 먼저 Mac에서 연결을 저장하고 Windows에서 저장합니다. 두 번째 저장부터 양쪽의 연결 기기 수가 1대가 될 때까지 걸린 시간을 기록합니다.
- 연결이 안 되면 **다시 찾기**를 한 번 누르고 10초 정도 관찰합니다.
- 양쪽에서 **기기 연결 → 연결 상태 복사**를 누르고 ChatGPT에 각각 `Mac`, `Windows`라고 표시해 붙여 넣습니다. 이 보고서는 버전·OS/CPU·연결 수·LAN 준비/광고 수·외부 탐색 노드 수·오류 코드만 포함합니다. 연결 키, 비밀번호, 파일명, 클립보드 내용, IP 주소, 기기 이름은 포함하지 않습니다. 보고서는 기록하거나 다른 PC에 동기화하지 않습니다.

두 보고서의 버전, LAN 준비 여부, 광고 수, 오류 코드를 비교합니다. 양쪽 광고가 0이면 권한·방화벽·공유기 차단부터 확인하고, 광고는 오는데 연결 수가 0이면 키/비밀번호 일치와 TCP 허용을 확인합니다. 외부 탐색 노드 수가 0이어도 정상적인 내부 연결은 가능합니다.

## 복사·붙여넣기 확인

| 순서 | 조작 | 기대 결과 |
| --- | --- | --- |
| 1 | Mac 메모장에서 `맥 → 윈도우 한글 검증 123` 복사 | Windows 메모장에 붙여넣기 가능 |
| 2 | Windows에서 `윈도우 → 맥 검증 ABC` 복사 | Mac 메모장에 붙여넣기 가능 |
| 3 | Mac에서 스크린샷을 클립보드에 복사(`Control+Command+Shift+4`) | Windows 그림판 등에 이미지 붙여넣기 가능 |
| 4 | Windows에서 스크린샷 복사(`Win+Shift+S`) | Mac 메모 등에 이미지 붙여넣기 가능 |
| 5 | Finder에서 `한글 파일 시험 ①.txt` 복사 | Windows 탐색기에서 붙여넣기, 파일명·본문 동일 |
| 6 | Windows에서 다른 한글 파일을 복사 | Mac Finder에서 붙여넣기, 파일명·본문 동일 |
| 7 | Mac 창의 ×를 누른 뒤 Windows에서 새 텍스트 복사 | 메뉴바에는 앱이 남고 Mac에서 붙여넣기 가능 |
| 8 | 한쪽 앱을 완전히 종료 후 재실행 | 키 재입력 없이 연결 복귀; 새로 복사한 내용 동기화 |

처음에는 작은 파일로 확인합니다. 프로그램은 전송만 확인하고 자동 실행하지 않습니다. 폴더·macOS .app은 ZIP으로 압축합니다. 동기화 중 큰 파일보다 최신 내용을 복사하면 최신 클립보드가 우선이므로 대용량 검사 중에는 추가 복사를 멈춥니다.

큰 파일의 바이트 보존을 확인하려면 원본과 수신 파일의 SHA-256을 비교합니다. 두 명령 모두 실제 파일 경로로 바꿔 실행하세요.

Mac 터미널:

```sh
shasum -a 256 '/실제/파일/경로'
```

Windows PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\실제\파일\경로'
```

## 결과 기록

- Mac: macOS 버전 / CPU / ClipSync 버전
- Windows: Windows 버전 / ClipSync 버전
- 같은 공유기 여부 / VPN 여부
- 최초 연결 시간 / 재실행 후 연결 시간
- 실패한 단계와 화면에 보인 오류
- 양쪽의 **연결 상태 복사** 보고서

인터넷을 통한 연결은 내부 검사가 성공한 다음, 한쪽을 휴대전화 핫스폿 등 다른 회선으로 옮겨 별도로 검사합니다. 다른 회선에서만 실패한다면 NAT·UDP 제한을 우선 확인합니다. 내부 연결 성공만으로 외부망 연결을 검증했다고 판단하지 않습니다.
