# 0.4.9 · 빌드 9 · 업데이트 알림과 다운로드

설치 앱은 실행 15초 후와 6시간마다 공식 GitHub 릴리스 API의 최근 20개를 확인합니다. 버전 세 자리 숫자를 비교하여 더 높은 버전의 이 PC용 업로드 완료 설치 파일을 선택합니다. Windows x64, Mac arm64·x64를 구분하며 GitHub prerelease도 미리보기 표시와 함께 안내합니다. 초안은 제외하고 새 버전의 설치 파일이 아직 없으면 준비 중으로 안내합니다.

OS 알림과 앱 안의 지속적인 배너를 표시하고, OS 알림 클릭은 앱을 엽니다. Windows 앱 ID와 설치된 시작 메뉴 바로가기를 연결합니다. 마지막으로 표시한 알림 버전만 기기에 기록해 재실행 시 같은 알림을 반복하지 않습니다. OS 알림이 지원되지 않거나 차단되어도 앱의 배너·환경설정 버튼은 사용할 수 있습니다.

환경설정에서 자동 확인을 끌 수 있으며 수동 확인은 별도로 가능합니다. 개발 실행에서는 자동 요청하지 않습니다. 요청은 단일 실행으로 합치고 완료 후 60초간 재사용합니다. 15초 타임아웃·1MiB 응답 제한, HTTP·JSON 오류 처리를 적용하며 실패를 최신 버전으로 표시하지 않습니다. 종료 시 진행 중 요청과 타이머를 정리합니다.

렌더러는 임의 다운로드 주소를 전달하지 못합니다. 신뢰한 메인 프레임만 IPC를 호출하고 메인 프로세스가 공식 저장소의 정확한 태그·설치 파일명·공개 주소를 대조합니다. 다운로드는 해당 주소를 OS 브라우저로 전달합니다. 설치 파일을 자동 실행하거나 무인 설치하지 않습니다. Windows 서명·Apple 공증이 아직 없으며 이번 구현은 서명된 자동 설치 체계를 대신하지 않습니다.

GitHub 요청에는 고정 User-Agent와 API 헤더만 지정합니다. 클립보드·키·비밀번호·기기 이름·고유 ID를 보내지 않습니다. 자동 확인의 네트워크 메타데이터 처리를 개인정보처리방침·이용약관 문서 1.1에 반영했습니다. 버전 비교는 로컬에서 수행합니다.

## 검증

- 타입 검사·프로덕션 빌드와 단위·소켓 검사 58개 통과.
- 추가 검사는 0.4.10과 0.4.9의 숫자 비교, OS·CPU 선택, 미리보기, 초안·외부 URL·완료 전 파일·크기 한도·잘못된 응답 거부, 중복 호출·요청 헤더·응답 복제·요청 제한·취소·네트워크 오류를 확인합니다.
- 실제 Linux Electron·Secret Service에서 자동 확인 옵션 저장·복원, 최소 360×480의 고정 버전·빌드 표시, 정책 원문·오프라인 열람, 기존 기록·암호화·포커스 검사를 통과했습니다. Linux 설치 파일은 제공하지 않아 해당 환경에서는 다운로드를 지원하지 않는다고 표시합니다.
- Windows·Mac 네이티브 검사는 공식 API 주소의 요청을 테스트 응답으로 대체하여 새 버전 표시·미리보기·OS와 CPU에 맞는 정확한 다운로드 주소·연속 확인 억제·설정 유지 여부를 확인합니다. 다운로드 버튼 테스트에서는 실제 브라우저 실행 대신 전달된 주소를 검사합니다.

실제 OS 알림 표시 여부는 알림 권한·집중 모드에 영향을 받습니다. 사용자 기기의 OS 알림·설치 화면·재부팅을 클라우드에서 확인했다고 주장하지 않습니다.

[OS별 CI](https://github.com/limfrog/ClipSync/actions/runs/39552638203)는 제품 커밋 `d84be5c`에서 2분 17초 만에 네 환경 모두 성공했습니다. Windows·Mac 두 종류의 네이티브 UI와 다운로드 주소 검증 및 기존 클립보드·500MB·중복 수신·기록 유지·자동 시작 검사를 통과했습니다.

[설치 파일 배포 검사](https://github.com/limfrog/ClipSync/actions/runs/39552907480)는 태그 `v0.4.9`에서 4분 16초 만에 성공했습니다. Windows x64·Mac arm64/x64 설치 파일의 앱 0.4.9·빌드 9, 원본과 동일한 정책 1.1 문서와 아이콘을 검사했습니다. Windows 실행 파일·설치 파일의 네이티브 버전은 0.4.9.9, Mac CFBundleVersion은 9입니다. Mac 서명 무결성과 PKG 확장 검사도 통과했습니다.
