# 0.4.7 창·선택 표시·기록 유지 검증

## 창과 포커스

프레임 없는 창을 최소 360×480부터 가로·세로로 조절합니다. 최대화 전의 크기와 위치를 원자적으로 저장하며 이전 버전의 위치만 있는 파일도 읽습니다. 모니터가 빠지거나 작업 영역이 작아지면 화면 안에 들어오도록 조정합니다. 낮은 해상도에서 저장한 높이가 재실행 때 반복해서 줄어들지 않도록 기본 크기의 여백과 저장 크기의 제한을 구분합니다. 필터는 비율을 유지하는 그리드이며 긴 단축키는 말줄임합니다.

기존 `blur` 즉시 숨김과 Mac 트레이 메뉴·클릭의 토글 중복 경로를 제거했습니다. Mac은 네이티브 메뉴의 열기 항목을 사용하고, 모든 명시적 열기 요청은 이미 열린 창을 계속 표시합니다. ×·Esc·단축키는 숨김, 종료는 전체 종료를 유지합니다. 테스트는 원래 창의 blur와 보조 네이티브 창의 포커스·해제를 반복합니다. 사용자의 물리 Mac에서 발생한 정확한 이벤트 순서를 기록한 검사는 아닙니다.

## 선택과 Windows 아이콘

선택된 기록에 2px 테두리·왼쪽 강조선·16% 강조색 배경·선택 배지·`aria-current`를 적용합니다. 고정 항목 정렬 후 첫 번째 카드를 무조건 선택하던 표시도 고쳤습니다.

Windows용 아이콘은 기존 A 아트워크의 투명 여백만 줄인 크기 변환본입니다. 새 그림을 적용하지 않으며 Mac 아이콘은 유지합니다. Windows 창·PE·설치 파일은 확대된 그림을 쓰고 트레이는 여러 크기를 포함한 전용 ICO를 사용합니다. OS 아이콘 슬롯의 크기 자체를 바꾸는 방식은 아닙니다. 표시 중인 창은 Windows 작업표시줄에도 나타납니다.

## 기록 저장

사용자가 기록 유지를 켠 경우만 저장합니다. 텍스트·파일 경로·순서·고정 상태를 DPAPI/Keychain/Secret Service의 암호화로 `history.enc`에 보관합니다. 최대 100개·텍스트 합계 4MiB 제한을 유지하고 손상·버전·경로·미디어 메타데이터·텍스트 길이를 검사합니다. 보안 저장소를 쓸 수 없으면 평문 저장으로 대체하지 않습니다.

자동 저장은 기록 변경에만 예약하며 전송 진행률 갱신으로 이미지나 큰 텍스트를 반복 저장하지 않습니다. 설정 변경·자동 저장·종료 저장을 직렬화하고 종료 시 최신 기록 저장을 기다립니다. 이미지 바이트는 스트리밍 파일 복사로 사용자별 `history-images` 폴더에 유지하며 이미지 자체는 암호화하지 않습니다. 파일 기록은 원본 경로를 참조하여 500MB 프로그램을 기록용으로 추가 복사하지 않습니다. 삭제·이동된 원본은 기록을 남기고 복사 시 오류를 안내합니다.

기록을 지우면 앱 소유의 불필요한 이미지 캐시도 정리합니다. 옵션을 끄면 암호화된 저장 기록을 삭제하며 현재 실행의 이미지 참조는 종료까지 유지한 후 삭제합니다. 다운로드 파일·사용자 원본은 삭제하지 않습니다. 다음 실행의 복원은 클립보드 쓰기·다른 기기로 전송을 하지 않습니다.
